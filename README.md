# QUEUELESS – Digital Queue Management System

### Wait Less. Know More.

QUEUELESS is a digital queue management prototype designed to reduce
physical waiting and provide real-time queue information.

## Features

- Digital token generation
- Service selection
- Live queue display
- People-ahead counter
- Estimated waiting time
- Customer status
- Admin dashboard
- Call Next functionality
- Served-token history
- Reset demo functionality
- Responsive mobile design

## Technology

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- GitHub Pages

## Project Flow

Customer
↓
Select Service
↓
Generate Token
↓
Track Queue
↓
Receive Turn
↓
Service Counter

Admin
↓
View Queue
↓
Call Next
↓
Serve Customer
↓
Complete Token

## Disclaimer

This is a college project prototype. It uses browser LocalStorage
and does not provide real multi-user server synchronization.
